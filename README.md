## 🔐 Security Model
- **Classification**: AUDITORIA PASSIVA / ENUMERAÇÃO
- **Higiene Digital**: Análise de configurações e metadados públicos ou acessíveis de forma não autenticada, seguindo as diretrizes de programas de Bug Bounty.
- **Mitigações Ativas**:
  - *Ameaça:* Acesso ao Metadata Service a partir de um contêiner comprometido → *Mitigação:* A ferramenta verifica a acessibilidade do endpoint 'http://metadata.google.internal' e a presença do cabeçalho 'Metadata-Flavor: Google', simulando uma tentativa de SSRF para extrair tokens de Service Account.
  - *Ameaça:* Escalação de Privilégios via IAM → *Mitigação:* Análise de permissões de um Service Account (se um token for obtido ou fornecido) contra uma base de conhecimento de permissões perigosas como 'iam.serviceAccounts.actAs', 'iam.serviceAccountKeys.create', e 'resourcemanager.projects.setIamPolicy'.
